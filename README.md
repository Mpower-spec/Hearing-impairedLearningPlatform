# 声学无碍学习平台

面向听障学生的无障碍学习平台，围绕“字幕优先、课堂同步、课后复习”构建完整学习闭环。平台包含教师端、学生端、实时课堂、AI 学习资料、视频学习、课程问答、手语数字人、学习社区和移动端响应式界面。

当前版本聚焦可访问性、实时内容和自主学习，不包含注册、账号管理后台和内容运营系统。

## 项目定位

平台解决三个核心问题：

1. **课堂信息可见**：把教师语音转成字幕，并同步 PPT、字幕、弹幕和课堂状态。
2. **课后内容可复习**：课堂记录、字幕、学习资料和视频笔记长期保留。
3. **学习差异可支持**：通过字幕设置、手语辅助、AI 问答和文字社区降低学习障碍。

设计原则：

- 字幕是核心信息，不依附于声音。
- 动态效果服务于内容，不干扰阅读。
- 教师端和学生端使用不同任务布局。
- AI 输出必须标明来源和降级状态。
- 无障碍设置优先于装饰性视觉。

## 核心功能

### 教师端

#### 课程与课件

- 上传 `.pptx` 课程文件。
- 校验文件扩展名和大小。
- 通过 LibreOffice 将 PPTX 转换为 PDF。
- 通过 Apache POI 提取幻灯片文字。
- 通过 PDFBox 计算 PDF 页数。
- 课程列表、PDF 预览和课程删除。
- 删除课程时同步清理课程、课堂、字幕、弹幕、资料和文件。

#### 实时课堂

- 为课程创建课堂房间。
- 自动生成唯一 6 位数字房间码。
- 教师切换 PPT 页码后实时广播给学生。
- 使用 Chrome/Edge Web Speech API 生成教师语音字幕。
- 提供内置备用字幕输入。
- 查看学生弹幕。
- 结束课堂并广播结束状态。

#### 备课与课堂资料

- 根据 PPT 提取文本生成备课资料。
- 备课资料包含教学目标、重点、术语、练习等结构化内容。
- 支持重新生成备课资料。
- 课堂结束后生成课堂学习资料。

### 学生端

#### 加入课堂与课堂记录

- 输入 6 位房间码预览课堂。
- 加入进行中的课堂并写入成员关系。
- 查看进行中和已结束课堂记录。
- 进行中课堂可直接继续进入，无需重复输入邀请码。
- 已结束课堂可查看字幕、弹幕和课后资料。

#### 课堂学习

- 查看同步 PPT 和页码。
- 阅读大字号实时字幕。
- 接收教师最终字幕和课堂弹幕。
- 发送文字弹幕。
- 查看历史字幕和弹幕记录。
- 课堂结束后自行生成或查看学习资料。
- 在课堂页使用基于当前课程资料的 AI 问答。

#### 视频学习

- 上传 MP4/WebM 视频。
- 通过 FFmpeg 提取 16kHz 单声道音频。
- 通过 SiliconFlow `FunAudioLLM/SenseVoiceSmall` 转写。
- 根据文本长度和视频时长生成估算时间轴 VTT。
- 使用 HTML5 `<video>` 播放视频和原生字幕。
- 根据 VTT 时间轴驱动手语数字人。
- 根据转写文本生成结构化学习笔记。
- 删除自己的视频及关联文件。

#### 学习社区

- 教师和学生均可发布文字帖子。
- 分类筛选、关键词搜索和分页。
- 查看帖子详情和评论。
- 删除自己发布的帖子或评论。
- 内容围绕课程问题、学习方法和经验交流。

### AI 能力

- 教师备课资料生成。
- 课堂学习资料生成。
- 视频转写与学习笔记生成。
- 学生课程问答。
- 课程问答限定为当前课程的 PPT 文本、课堂字幕和课堂学习资料。
- AI 回答附带引用片段和来源标记。
- AI 不可用时支持明确标记的模拟降级内容。

### 手语数字人

- 学生端使用全局单例数字人。
- 页面切换时复用同一个实例。
- 课堂最终字幕可驱动手语表达。
- 视频 VTT 字幕可按时间轴驱动手语表达。
- 支持欢迎语、重播、隐藏和显示。
- 数字人字幕队列只保留当前内容和最新待播放内容。
- 字幕 ID 去重，避免 WebSocket 重连造成重复表达。

## UI 设计

### 视觉方向

界面采用“声音极光”视觉语言：

- 深海蓝、青绿和琥珀色形成主色调。
- 深色玻璃页头与浅色内容卡片形成层次。
- 夜空背景包含静态银河、月亮辉光和星点。
- 桌面端保留流星、极光漂移和更丰富的动态效果。
- 移动端使用轻量模式，关闭流星、大型模糊动画和持续背景位移。
- 装饰元素使用 `aria-hidden`，不进入屏幕阅读器和键盘焦点顺序。

### 页头结构

页头分为三个区域：

```text
品牌区 | 主导航 | 用户与工具区
```

- 左侧：品牌名称和平台标识。
- 中间：首页、学习社区。
- 右侧：手语数字人控制、阅读设置、用户信息和退出登录。
- 页面附加操作放在第二行快捷操作区域。

### 首页

首页不使用轮播图，采用仪表盘式结构：

- 主学习台：欢迎信息、核心功能、行动按钮和字幕预览。
- 功能侧卡：同步课堂、视频学习或 AI 备课。
- 学习节奏面板：动态声波和辅助视觉。
- 快捷入口：矩形功能卡，覆盖课程、课堂、视频和社区。

### 教师端布局

三个核心页面使用不同布局：

- **课程资料库**：深青色资料架和课程封面卡片。
- **课堂指挥台**：深色控制台、实时状态灯、筛选侧栏和横向会话列表。
- **AI 备课工作室**：暖棕与琥珀色工作台、流程侧栏和横向课程行。

### 学生端布局

- 加入课堂：房间码输入与“我加入的课堂”记录并列呈现。
- 实时课堂：字幕置顶、PPT 全宽、控制栏在下方。
- 视频学习：视频播放器、字幕记录和笔记按学习流程排列。
- 学习社区：文字优先，卡片突出标题、摘要、作者和评论数。

### 响应式设计

| 屏幕宽度 | 布局 |
| --- | --- |
| `≤767px` | 手机单列、底部导航、紧凑页头 |
| `768–1119px` | 平板单列或双列 |
| `≥1120px` | 桌面多栏和完整动态效果 |

移动端特化：

- 视频、PPT 和表单使用全宽。
- 评论和发帖弹窗接近全屏。
- 输入字号不低于 16px。
- 底部导航使用安全区变量。
- 卡片滚动揭示、毛玻璃和持续动画被关闭或简化。

### 无障碍阅读设置

支持：

- 字幕字号：28–64px。
- 字幕行距：1.2–2.0 倍。
- 高对比度模式。
- 减少动画。
- 明亮和深色主题。

设置保存在浏览器 `localStorage` 的 `hp_accessibility_settings_v1` 键中。

核心 CSS 变量：

```text
--caption-font-size
--caption-line-height
--caption-history-font-size
--caption-card-bg
--caption-card-text
--reading-card-bg
--reading-card-border
--reading-card-text
```

### 视频字幕样式

- 原生 `<track>` 字幕。
- 背景透明。
- 白色字体。
- 多层黑色文字阴影。
- 不遮挡视频画面。

## 鉴权与权限

- 使用 JWT Bearer Token。
- 密码使用 BCrypt。
- 登录后由后端返回用户信息和角色。
- 前端把 Token 和用户信息保存在浏览器。
- 请求失效返回 `401`。
- 角色不足返回 `403`。
- 教师只能管理自己的课程、课堂和资料。
- 学生只能访问自己加入过的课堂和属于自己的视频。
- 课程 AI 问答仅允许房间成员使用。

REST 鉴权头：

```http
Authorization: Bearer <JWT>
```

## WebSocket 实时课堂

连接地址：

```text
/ws/classroom?token=<JWT>
```

服务端验证：

- JWT 是否有效
- 用户角色
- 房间状态
- 课程和课堂归属
- 学生成员关系

### 客户端消息

| `type` | 发送者 | 主要字段 | 说明 |
| --- | --- | --- | --- |
| `join` | 教师/学生 | `roomCode` | 加入课堂 |
| `slide` | 教师 | `page` | 切换 PPT 页码 |
| `caption` | 教师 | `text` | 保存并广播最终字幕 |
| `danmaku` | 教师/学生 | `content` | 保存并广播弹幕 |
| `end` | 教师 | 无 | 结束课堂 |
| `ping` | 教师/学生 | 无 | 心跳 |

### 服务端消息

| `type` | 主要字段 | 说明 |
| --- | --- | --- |
| `state` | 课程、房间、页码、页数、PDF、状态 | 完整课堂状态 |
| `slide` | `page` | 同步翻页 |
| `caption` | `id`、`text`、`createdAt` | 新最终字幕 |
| `danmaku` | `id`、`content`、`userName`、`createdAt` | 新弹幕 |
| `end` | 无 | 课堂结束 |
| `pong` | 无 | 心跳响应 |
| `error` | `message` | 错误提示 |

权限规则：

- 只有教师可以翻页、发送最终字幕和结束课堂。
- 教师和学生可以发送弹幕。
- 学生发送翻页、字幕或结束消息会被拒绝。
- 所有广播严格按房间隔离。

## AI 与媒体流程

### PPTX 转 PDF

```text
上传 PPTX
  -> 校验扩展名和大小
  -> UUID 文件名保存
  -> LibreOffice 转 PDF
  -> POI 提取文本
  -> PDFBox 计算页数
  -> 保存课程
```

### 视频字幕

```text
上传 MP4/WebM
  -> FFmpeg 提取 16kHz 单声道音频
  -> SenseVoice 转写
  -> 按句长和视频时长估算 VTT 时间轴
  -> HTML5 video 加载 VTT
  -> 字幕驱动手语数字人
```

SenseVoice 当前返回整段文本，因此 VTT 时间轴为估算值，不是逐词时间戳。

### 课程问答检索

```text
问题
  -> 提取中文双字词和英文词
  -> 从 PPT、课堂字幕、课堂资料中切块
  -> 关键词命中评分
  -> 选择最多 5 个相关片段
  -> 构造 Prompt
  -> LLM 回答
  -> 返回引用来源
```

当前不使用 Embedding、向量数据库或全文检索中间件。

### AI 运行模式

| 模式 | 行为 |
| --- | --- |
| `real` | 只使用真实接口，失败直接报错 |
| `auto` | 优先真实接口，失败时使用明确标记的本地兜底内容 |
| `mock` | 不调用远程 AI，直接生成本地兜底内容 |

AI 回答不记录到数据库；课程问答历史只保留在当前页面会话内。

## 安全与隐私注意事项

### 安全上下文

以下能力依赖安全上下文：

- 浏览器麦克风
- Web Speech API
- 手语数字人 SDK

非安全页面可能出现麦克风禁止、SDK 初始化超时或 WebGL 资源无法进入动作服务。

### 手语数字人

- 在线 SDK 依赖 `avatar.gbqr.net`、`api.gbqr.net` 和 WebSocket。
- 当前账号存在并发席位限制。
- 多学生同时使用需要多席位授权或集中渲染方案。
- 数字人失败不能阻断字幕、视频和课堂主流程。
- 隐藏或离开课堂时应取消当前手语表达并清空队列。

### 浏览器语音识别

- Web Speech API 主要支持 Chrome/Edge。
- 依赖浏览器版本和网络环境。
- 识别结果和延迟不可控。
- 浏览器不支持时必须有备用字幕输入。

### AI 输出

- AI 回答只作为学习辅助，不应替代课程原文。
- 资料不足时应明确说明，不应编造。
- 回答必须保留来源标记。
- 模拟内容必须显示 `MOCK` 或同等提示。

### 文件访问

当前 `/files/**` 使用不可预测的 UUID 文件名，但没有额外业务鉴权。涉及敏感课程、视频或录音时，需要增加签名 URL、登录校验或对象存储私有读权限。

### 视频时间轴

- VTT 时间轴根据句长和视频总时长估算。
- 不保证逐词同步。
- 长句被切分后，字幕结束时间可能存在偏差。
- 手语动画速度由 SDK 决定，不保证与字幕完全同步。

### 移动端性能

- 手机端关闭流星、大型模糊动画、持续背景位移和滚动揭示。
- PC 端保留完整视觉动效。
- 减少动画设置会进一步降低动态效果。
- 高对比度模式会隐藏纯装饰背景。

### 数据与隐私

- 课堂字幕、弹幕和视频内容可能包含学习隐私。
- 录音和上传前应获得参与者知情同意。
- 日志不得记录密码、JWT、API Key、字幕正文和弹幕正文。
- 本地配置和真实账号不得提交到 Git。

## 当前限制

- 不支持用户注册、找回密码和账号管理后台。
- 不支持教师跨账号协作。
- 不支持 PPT 动画、内嵌视频和复杂版式还原。
- 不支持视频转码、HLS 和对象存储。
- 社区仅支持文字帖子、评论、分类、搜索和分页。
- 不支持图片、附件、点赞、私信和内容审核后台。
- 课程问答不支持跨课程资料。
- 课程问答不保存聊天历史。
- 手语数字人不支持自定义离线模型和词元库。
- 单数字人账号不能保证多学生并发使用。
- 实时字幕依赖教师端浏览器和网络。
- AI 和 ASR 服务不可用时会进入降级流程。
